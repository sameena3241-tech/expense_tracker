# **💰 Expense Tracker**

A simple **Expense Tracker application** built using **Python and Object-Oriented Programming (OOP).**

The program allows users to **add expenses, view recorded expenses, and calculate the total expense.**


## **✨ Features**

- ✅ **Add a new expense**
- ✅ **View all recorded expenses**
- ✅ **Calculate total expenses**
- ✅ **Handle invalid amount input using "try-except"**
- ✅ **Menu-driven console application**
- ✅ **Object-Oriented Programming**

## **🛠️ Technologies Used**

- **Python**
- **Object-Oriented Programming (OOP)**
- **Exception Handling**

## **▶️ How to Run**

**Step 1**: Clone the repository.

**Step 2**: Open the project folder in VS Code or any Python editor.

**Step 3**: Run the program:

```
Expense Tracker.py
```

**Step 4**: Select an option from the menu:

```
===== Expense Tracker =====

1. Add Expense
2. View Expenses
3. Total Expense
4. Exit
```
